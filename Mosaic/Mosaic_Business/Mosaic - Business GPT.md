# 1) PRODUKT

(_Co buduješ. Co je jeho hodnota. Jak má růst._)

Tady jsou tři vrstvy, které musí být jasné, pokud chceš Mosaic rozvíjet systematicky nebo z něj udělat startup.

## 1.1 Core produkt

To je to, co Mosaic _je_:

- osobní datový systém
    
- ingest (wearables, health, entries, activities)
    
- normalizace + ETL
    
- analytics + statické a dynamické metriky
    
- PWA + offline režimy
    
- bezpečnost, privacy-first
    
- multi-device
    

Tento core musí být **technicky stabilní** a „investovatelné-pochopitelný“.

## 1.2 Produktové moduly (monetizační vrstvy)

Nové moduly, které se dají prodávat:

- Premium Analytics (trendy, predikce, score)
    
- Health Connect Sync Pro
    
- NightMotion (pokud to bude produkt)
    
- Backup Manager
    
- AI Insight Layer
    
- Wearable Deep Stats (HRV, cadence, sleep architecture)
    

Každý modul by měl být:

- oddělitelný
    
- licencovatelný
    
- samostatně vyvíjený
    

## 1.3 Produktová strategie (dvouletá)

V podstatě:

**Rok 1:**  
– Mosaic 1.0 (stabilní ingest + analytics)  
– Mosaic Pro (subscription)  
– Minimal marketing

**Rok 2:**  
– Mosaic 2.0 (mobilní app + AI layer)  
– Partnerství / micro-B2B  
– Seed investice nebo organický růst

# 2) KAPITÁL

(_Kde vzít peníze. Jaký model je realistický. Jak se vyhnout tlaku, který tě zničí._)

Kapitalizace Mosaicu může mít tři formy. Vyber si jednu nebo míchat dvě.

## 2.1 Organický model (bez investorů)

Pomalý, stabilní, nízkotlaký.

Zdroje příjmů:

- subscription Mosaic Pro
    
- 1–3 micro-projekty ročně
    
- případné malé konzultace
    

Výhoda:  
**Nulový tlak, plná kontrola, minimum stresu.**

Nevýhoda:  
Pomalejší růst, menší rozsah.

## 2.2 Angel model

Pro tebe realistický, pokud máš:

- MVP
    
- pricing
    
- showcase datové analytics
    
- jasnou vizi
    

Obvykle 0,5–1,5 mil. Kč.

Výhoda:  
**Volnost vytvořit Mosaic 2.0 v klidu.**

Riziko:  
musíš mít co-foundera na obchod  
(ne ty, protože by tě to vyčerpalo).

## 2.3 Pre-seed / Seed model

Možné až když:

- Mosaic má klienty
    
- máš jasný tržní segment
    
- produkt funguje multi-device
    
- existují use-casy mimo osobní využití
    

Výhoda:  
Rychlý růst, partnerské integrace, marketing.

Nevýhoda:  
Vyšší očekávání  
→ pro tebe nepříjemné.

# 3) INFRASTRUKTURA

(_Aby projekt vydržel tvoje výkyvy. Aby se nezhroutil, když máš 3 týdny depresi nebo útlum._)

Toto je nejdůležitější osa pro tvou psychiku.

## 3.1 Technická infrastruktura

Musí být modulární, samo-opravná a nízkonákladová.

- Docker Compose (backend + db)
    
- Caddy (reverse proxy + certs)
    
- PostgreSQL + zálohy
    
- CI/CD (GitHub Actions)
    
- PWA service worker
    
- Monitoring (healthz, metrics)
    
- Logging (uvicorn + rotating logs)
    

Cíl:  
**i když 2 týdny nic neděláš, systém stojí, běží a nevyžaduje péči.**

## 3.2 Procesní infrastruktura (to, co potřebuješ ty)

Tvoje psychika potřebuje toto:

- práce po blocích (3–6 h hyperfokus)
    
- 100% odpojitelný režim (bez zodpovědnosti vůči lidem)
    
- backlog 5–7 uzavřených mini-bloků
    
- žádné dlouhé sprinty
    
- žádné rozpracované megatasky
    
- modulární roadmapa (ne sekvenční)
    

Tohle je zásadní podmínka, jinak shoříš.

## 3.3 Organizační infrastruktura (pro případ startupu)

Pokud budeš dělat startup, potřebuješ:

- **co-foundera obchod/marketing**
    
- nikoho dalšího první 12–18 měsíců
    
- právní rámec (s.r.o. nebo projektová smlouva)
    
- jednoduchý rozdělovník:
    
    - ty: 70–80 % tech
        
    - on/ona: 20–30 % obchod + fundraising

# FINÁLNÍ MODEL (3 OSY DOHROMADY)

**Produkt**  
→ Mosaic 1.0 (ingest + analytics + PWA offline)  
→ Mosaic Pro/Premium (subscription)  
→ Mosaic 2.0 (mobilní app + AI analytics)

**Kapitál**  
→ organicky + malý angel round (pokud bude vhodný partner)  
→ žádné půjčky  
→ žádný tlak

**Infrastruktura**  
→ modulární technická  
→ nelineární procesní  
→ s co-founderem pro obchod

Tohle je **jediný model**, který je kompatibilní s tvojí osobností _a zároveň_ umožňuje Mosaic škálovat na startupové parametry.
